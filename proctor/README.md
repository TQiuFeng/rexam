# 监考端

装在**老师自己那台电脑**上。考试当天用它取号、看考场；考前维护用它布机。

1. 双击 `rexam-proctor.exe`
2. 填服务器地址、用教师或管理员账号登录
3. 选一场已发布的考试，点「进入考场」

进来默认是**看板**。功能在上面的菜单栏上：`看板 / 取号 / 布机`。

## 看板

一台电脑一块砖，像监控墙那样铺满。顶上一行是这场考试的时间安排 ——
几点开、几点截止、限时多久、现在距开考（或距截止）还有多久。

![看板](../docs/screenshots/proctor/01-board.png)

砖**按座位号排，不按状态排**：位置固定才有肌肉记忆，「3 号在左上角第三块」
永远成立；按状态排的话砖每几秒跳一次位置，反而找不着人。

颜色只表示「要不要过去看一眼」：

| 颜色 | 意思 |
|---|---|
| 红 | 掉线 —— 机器绑过但超过 30 秒没心跳 |
| 蓝 | 答题中 |
| 灰/白 | 其余（未取号、等待开考、已交卷、空座） |

「已交卷」**不给绿色**：绿容易被读成「答得对」，而交没交卷和答得怎么样是两回事。

点任意一块弹详情：照片核对、补 10 分钟、强制交卷。

## 取号

考生走到讲台报名字，搜一下，**对着照片确认是本人**，再取号。

![取号](../docs/screenshots/proctor/02-checkin.png)

两种考场走两条路，由建考试时选的「座位分配方式」决定：

| 分配方式 | 机器连上来时 | 学生到场时 |
|---|---|---|
| **现场随机取号** | 机器只占住座位号，不带人 | 点「取号」→ 系统从空闲机器里**随机抽一台** → 大字报号 |
| **提前全部分配** | 机器领座位号时顺带领走一个还没排座的考生 | 点「确认到场」 |

随机是现场取号的全部意义：考生事先不知道自己会坐哪台机器。

抽号在服务端做，整场加锁 —— 两个老师在两台监考端同时取号，不会把两个学生
指到同一台机器上。同一个人重复点返回原来那个号，不会给他第二台。

考生照片在管理后台的「用户管理 → 批量导入照片」里整批传。库里没照片的人，
取号页会提示「只能凭证件核对」。

## 布机

维护人员用的那一套：开始布机之后，考场机开机会自己找过来领座位号。
屏幕上的「连上 N 台 / 应到 M 台」就是布机进度，另外还有信标发包数、
探询次数、主机名、IP —— 排查网络问题时要看这些。

散场在看板底部点「全部放行」，全场机器解除锁定。

### 换机

考场机坏了，在它那一行点「换机」，然后把备用机开机 —— 备用机会自动顶到同一个座位号。

只「解绑」不行：认领记录还留着，服务端按 device_id 找不到备用机、
又发现名单里的人都排完了座，会直接拒绝。「换机」是把两样一起清。

### 要通的端口

| | 端口 | 谁监听 |
|---|---|---|
| 发现 | UDP 45301 | 双方 |
| 布机 | TCP 45300 | 本机 |

**第一次运行时 Windows 防火墙会弹窗，要点「允许」。** 点了取消的话：
出站的广播照发，考场机能「发现」到这台电脑，但连不上来 ——
症状很像「发现不了」，方向完全反了，容易一路查到交换机上去。

## 其他

程序旁边会生成 `proctor.json`，里面只有服务器地址、上次用的账号名和一个实例 id，
**没有密码**。实例 id 不要删：删了等于换了一台监考端，已经连上的考场机要全部重来。

界面字体是随程序带的 Noto Sans SC（SIL OFL，许可证见 `licenses/`），
不依赖系统装了什么字体。
